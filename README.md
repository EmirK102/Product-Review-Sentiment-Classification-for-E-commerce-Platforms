# Product-Review-Sentiment-Classification-for-E-commerce-Platforms

Q: What is this?

A: A college student group project aimed at creating an AI model with the purpose of classifying how many stars out of five were given to a product in a product review, based on its written textual review. This model is intended for sentiment classification in a variety languages, including English. It is constructed from two AI models: 

  1.) Libretranslate, an open-source and offline-capable text translation software.
  2.) ModernBERT, a drop-in replacement for BERT which is used in this project for text classification.

The program works like so: Libretranslate is used for translating non-English reviews into english, and the resulting output is fed into ModernBERT for sentiment classification.
